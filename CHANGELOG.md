# Changelog

All notable user-facing changes to DismissMeNot are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-19

### Added

- Responsive fake desktop and persistent notification experience.
- Ten randomized dismissal-refusal behaviors with immediate-repeat protection.
- Shared dismissal-attempt tracking and peaceful completion on attempt 10.
- Cascading multi-notification stacks with reachable controls.
- Mouse, touch, keyboard, and screen-reader interaction support.
- Modal focus management, live status announcements, and visible focus states.
- Reduced-motion and forced-color support.
- Locally generated Web Audio feedback with sound and reset controls.
- Static-site manifest, scalable favicon, security metadata, and deployment guidance.
- Dependency-free behavior and project-contract tests.
